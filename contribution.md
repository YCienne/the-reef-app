# Contributing to The Reef E-Learning Platform

Thank you for your interest in contributing to The Reef E-Learning Platform!  
We welcome and appreciate all contributions, whether you are fixing bugs, improving documentation, or adding new features.

---

## How to Contribute

1. **Fork the Repository**
    - Click the 'Fork' button at the top right of this repo.

2. **Clone Your Fork**
    ```bash
    git clone https://github.com/your-username/the-reef.git
    cd the-reef
    ```

3. **Create a Feature Branch**
    ```bash
    git checkout -b feature/my-feature
    ```

4. **Make Your Changes**
    - Write clear, concise code.
    - Update/add documentation as needed.
    - Ensure your code passes linting and tests.

5. **Commit Your Changes**
    ```bash
    git add .
    git commit -m "Describe your changes"
    ```

6. **Push to Your Fork**
    ```bash
    git push origin feature/my-feature
    ```

7. **Open a Pull Request**
    - Go to your fork on GitHub and click "New Pull Request."
    - Make sure your pull request clearly states:
        - What problem it solves or feature it adds.
        - Any related issue numbers.
        - Steps to reproduce if it's a bugfix.

---

## Guidelines

- Follow our [Code of Conduct](CODE_OF_CONDUCT.md).
- Write clear and descriptive commit messages.
- Keep pull requests focused and atomic—avoid combining unrelated changes.
- Include tests for new features or bug fixes if relevant.
- Ensure all checks pass before requesting a review.
- Be respectful and collaborative in all interactions.
